## Options

| Prop | Type | Description |
| --- | --- | --- |
| `onRowPress` | `(row) => void` | A row was tapped outside selection. |
| `onRowLongPress` | `(row) => void` | A row was long-pressed. |
| `onRowLongPressDetails` | `(params: RowLongPressParams) => void` | Long press, with `row`, `rowId`, and `position`. |
| `onCellPress` | `(params: CellEventParams) => void` | A cell was tapped. Receives `row` and `column`. |
| `onCellLongPress` | `(params: CellEventParams) => void` | A cell was long-pressed. |

## Order

A cell tap calls `onCellPress`, then runs the row press. While rows are selectable, a tap toggles selection instead of calling `onRowPress`.

## Client vs server

Events behave the same in both modes.
