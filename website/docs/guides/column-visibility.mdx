## Options

| Prop or field | Type | Default | Description |
| --- | --- | --- | --- |
| `columnVisibilityModel` | `ColumnVisibilityModel` | `{}` | Map of `field` to visibility. Only `false` hides a column. |
| `onColumnVisibilityModelChange` | `(next: ColumnVisibilityModel) => void` | None | Called when visibility changes. |
| `column.hideable` | `boolean` | `true` | Set `false` to keep the column out of the menu. |

## Client vs server

Visibility is handled by the grid in both modes. Hidden columns are still included in search.
