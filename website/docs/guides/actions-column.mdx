A column with `type: 'actions'` puts the actions on the row, so they don't depend on a long press.

## Options

| Field | Type | Description |
| --- | --- | --- |
| `type` | `'actions'` | Marks the column as actions. It is excluded from sort, filter, and search. |
| `actions` | `GridRowActionsSource` | Items, or a function returning them. |
| `actionTrigger` | `GridActionCellTrigger` | The cell's `icon`, `label`, and `display`. |

## Display order

The cell uses `actionTrigger.display` first, then the item's `displayInCell`. Without either, it shows both when it has an icon and a label, otherwise whichever exists.

## Client vs server

Actions columns behave the same in both modes.
