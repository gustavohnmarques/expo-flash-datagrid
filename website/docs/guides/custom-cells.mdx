## Options

| Field | Type | Description |
| --- | --- | --- |
| `valueGetter` | `(row) => unknown` | Computes the cell value. Sort, filter, and search use this value. |
| `valueFormatter` | `(value, row) => string` | Formats the value for display. Global search also matches this text. |
| `renderCell` | `(params: CellRenderParams) => ReactNode` | Replaces the cell's content. |
| `renderHeader` | `(params: HeaderRenderParams) => ReactNode` | Replaces the header's content. |

`renderCell` receives `row`, `value`, `rowId`, `field`, `rowIndex`, `column`, and `isSelected`. `renderHeader` receives `column` and `sortDirection`.

## Client vs server

These options only affect rendering in server mode. In client mode, `valueGetter` also feeds the sort, filter, and search steps.
