## Options

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `loading` | `boolean` | `false` | Shows the overlay and suppresses the empty state. |
| `loadingOverlay` | `ReactNode` | Built-in spinner | Replaces the overlay's content. |
| `refreshing` | `boolean` | `false` | Pull-to-refresh indicator. Only used with `onRefresh`. |
| `onRefresh` | `() => void` | None | Enables pull-to-refresh. |

## Client vs server

Both props are display-only, and work the same in both modes. In server mode you typically tie `loading` to the request.
