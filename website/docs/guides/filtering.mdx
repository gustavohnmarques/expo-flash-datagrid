## Options

| Prop or field | Type | Default | Description |
| --- | --- | --- | --- |
| `filterModel` | `FilterModel` | `{ items: [], logicOperator: 'and' }` | Controlled filters. |
| `onFilterModelChange` | `(next: FilterModel) => void` | None | Called when filters change. |
| `maxFilters` | `number` | `1` | Most filters a user can add. Minimum 1. |
| `filterModel.logicOperator` | `'and' \| 'or'` | `'and'` | How filters combine. |
| `column.filterable` | `boolean` | `true` | Set `false` to exclude a column. |
| `column.filterSelectOptions` | `FilterSelectOption[]` | None | Values offered by the picker. |
| `column.filterSelectMultiple` | `boolean` | `false` | Allow several selected values. |

Actions columns are never filterable.

## Default operators

| Column | Operators |
| --- | --- |
| `string`, `actions`, `custom` | `contains`, `doesNotContain`, `equals`, `doesNotEqual`, `startsWith`, `endsWith`, `isEmpty`, `isNotEmpty`, `isAnyOf` |
| `number` | `equals`, `doesNotEqual`, `>`, `>=`, `<`, `<=`, `isEmpty`, `isNotEmpty` |
| `date`, `datetime` | `is`, `not`, `before`, `onOrBefore`, `after`, `onOrAfter`, `isEmpty`, `isNotEmpty` |
| `boolean` | `is`, `isEmpty` |
| With `filterSelectOptions` | `equals`, `doesNotEqual`, `isAnyOf`, `isEmpty`, `isNotEmpty` |

Date filters accept ISO strings like `2024-01-31` and localized input like `31/01/2024`. A `date` column compares by day, and `datetime` keeps the time. The date picker opens on iOS and Android.

## Client vs server

In client mode the grid applies the operators. In server mode it reports `filterModel`, and your API interprets each `operator` and `value`.
