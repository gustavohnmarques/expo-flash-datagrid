## 0.3.0

- Developed and tested on Expo SDK 57 and React Native 0.86.
- Added `drawDistance`, forwarded to FlashList.
- Deprecated `estimatedItemSize`, which FlashList v2 no longer uses.
- Removed the unused `cardViewBreakpoint` prop and `toolbarExport` locale key.

See the [migration guide](/docs/migration-0-3).

## 0.2.1

- Clearing filters now also clears the local toolbar search.

## 0.2.0

- Added `serverSearchMode` and `serverLocalSearchText` for a hybrid local search in server mode.

## 0.1.1

- Improved filtering and search behavior.
