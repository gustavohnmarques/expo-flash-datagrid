| `react-native-safe-area-context` | `>=5.6.0` |
| `react`, `react-native` | Provided by your Expo SDK |

See [Compatibility](/docs/compatibility) for tested SDK versions.

## Wrap your app with SafeAreaProvider

The search, filter, column, and action menus are safe-area aware, so your app needs a provider at the root.

```tsx
import { SafeAreaProvider } from 'react-native-safe-area-context';

export default function App() {
  return (
    <SafeAreaProvider>
      <YourScreen />
    </SafeAreaProvider>
  );
}
```
