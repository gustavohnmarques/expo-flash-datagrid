---
title: Locale keys
---

Keys of `DataGridLocaleText`, with their English and Portuguese text. Override any of them through `localeText`. Strings marked with `{count}` are filled in with `formatLocale`.

## Toolbar

| Key | English | Portuguese |
| --- | --- | --- |
| `toolbarColumns` | Columns | Colunas |
| `toolbarFilters` | Filters | Filtros |
| `toolbarSearch` | Search | Buscar |
| `clearFilters` | Clear filters | Limpar filtro |
| `selectedRowsLabel` | `{count} selected` | `{count} selecionado(s)` |
| `clearSelection` | Clear | Limpar |

## Operator labels

`operatorLabels` is a `Record<string, string>` keyed by operator `value`. Add your custom operators here to translate them. Overrides merge key by key.

| Key | English | Portuguese |
| --- | --- | --- |
| `contains` | contains | contém |
| `doesNotContain` | does not contain | não contém |
| `equals` | equals | é igual a |
| `doesNotEqual` | does not equal | não é igual a |
| `startsWith` | starts with | começa com |
| `endsWith` | ends with | termina com |
| `isEmpty` | is empty | está vazio |
| `isNotEmpty` | is not empty | não está vazio |
| `isAnyOf` | is any of | é qualquer um dos |
| `>` | greater than | maior que |
| `>=` | greater than or equal to | maior ou igual a |
| `<` | less than | menor que |
| `<=` | less than or equal to | menor ou igual a |
| `is` | is | é |
| `not` | is not | não é |
| `before` | before | antes de |
| `onOrBefore` | on or before | em ou antes de |
| `after` | after | depois de |
| `onOrAfter` | on or after | em ou depois de |

The bundles also include labels for compatibility aliases: `=`, `!=`, `notContains`, `notEquals`, `between`, `isTrue`, and `isFalse`.
