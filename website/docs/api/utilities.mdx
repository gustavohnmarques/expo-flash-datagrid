## applyClientPipeline

Runs filter, search, sort, and paginate, and returns the rows after each step.

```ts
function applyClientPipeline<TRow>(params: {
  rows: TRow[];
  columns: ColumnDef<TRow>[];
  filterModel: FilterModel;
  searchText: string;
  sortModel: SortModel;
  paginationModel: PaginationModel;
  filterOperatorsByType?: FilterOperatorsConfig<TRow>['filterOperatorsByType'];
  filterOperatorsByField?: FilterOperatorsConfig<TRow>['filterOperatorsByField'];
}): {
  filteredRows: TRow[];
  searchedRows: TRow[];
  sortedRows: TRow[];
  paginatedRows: TRow[];
};
```

## getPaginationRange

Returns the one-based range shown in the footer, or zeros when `total` is 0.

```ts
function getPaginationRange(
  total: number,
  paginationModel: PaginationModel
): { from: number; to: number; total: number };
```

## getFilterOperatorsForColumn

Returns the operators that apply to a column, following the [resolution order](/docs/guides/custom-filter-operators#resolution-order).

```ts
function getFilterOperatorsForColumn<TRow>(
  column: ColumnDef<TRow>,
  options?: FilterOperatorsConfig<TRow>
): FilterOperator<TRow>[];
```

## getDefaultFilterOperatorsByType

Returns the built-in operators, keyed by column type.

```ts
function getDefaultFilterOperatorsByType<TRow = unknown>(): Record<ColumnType, FilterOperator<TRow>[]>;
```

## resolveLocaleText

Merges overrides over a built-in bundle.

```ts
function resolveLocaleText(
  locale?: DataGridLocale,
  overrides?: Partial<DataGridLocaleText>
```
