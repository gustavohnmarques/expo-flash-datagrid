# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

React Native developers building Expo apps with data-heavy screens (CRM, admin, inventory, finance), evaluating a table component or looking up its API while coding.

## Product Purpose

The documentation site for `expo-flash-datagrid`: explain what the library does, get people installed, and be the reference for props, types, and usage.

## Positioning

A real table on mobile: sorting, filters, search, pagination, and selection in one typed component, instead of building them on top of a list.

## Capabilities and Constraints

iOS and Android in Expo projects. Expo SDK 55 to 57 are verified. On Android, `listMode="auto"` uses FlatList. The grid has no export feature. The site shows code only: no interactive demo, iframes, or screenshots.

## Brand Commitments

Dark mode only, in dark blue tones. Follows the conventions of library documentation such as FlashList's: a landing page plus a docs area. Site copy is in English.

## Evidence on Hand

The library source and tests. There are no benchmarks, testimonials, or adoption figures, and none may be invented.
